# Weft Lab

Blender 5.3 袜面交互扩展。安装并启用后，在 3D 视口按 **N**，打开 **Weft Lab**。安装包内含脚踝固定回放。GitHub Release 另附丽莎演示工具，可以从官方模型在本机生成可抓取的工程。[获取丽莎演示工具](https://github.com/MrH0v0/weft-lab/releases/tag/v0.4.39)

角色绑定、干湿抓取、旧孔续撕和保存方式见[使用说明](USER_GUIDE.md)。Weft Lab 自研源码采用 MIT，完整 Blender 扩展同时按 GPL-3.0-or-later 提供。[MIT](licenses/Weft-Lab-MIT.txt) · [GPL](LICENSE.txt) · [素材与第三方声明](THIRD_PARTY_NOTICES.md)
