# Weft Lab 0.4.39 使用说明

## 选择操作对象

在 Blender 的 **偏好设置 → 获取扩展 → 从磁盘安装** 中选择 `weft_replay-0.4.39.zip` 并启用。打开 3D 视口侧栏的 **Weft Lab**。面板顶部显示正在操作的袜面、皮肤、姿势帧和模式。

- **丽莎示例**使用官方 1.4 模型和 Release 中的 `weft-lab-lisa-demo-0.4.39.zip` 在本机生成。打开生成的 `.blend` 即可在右腿选择干态或湿态抓取。[生成步骤](https://github.com/MrH0v0/weft-lab/blob/main/examples/lisa/README.md)
- **内置脚踝回放**可从 **参考样本 · 固定缓存回放 → 新建脚踝回放场景** 打开。时间轴第 34 帧停手，第 43 帧松手，第 55 帧是松手后 0.40 秒。可切换机位查看同一段织物。
- **自己的角色**需要同一骨架驱动的袜面和皮肤，按米建模，保持袜面拓扑稳定。在 **半自动袜面绑定** 指定原袜、皮肤，多材质身体可指定用于接触的皮肤材质。点 **在袜面点选抓点** 后点击踝部，再点 **生成回放副本**。骨名有歧义时手动指定膝骨和踝骨。

## 抓放、撕裂与加水

**干态抓取**在启动时的姿势下工作。在可见的袜面上按住左键向外拉，松手后可以换点。续撕时抓孔尖旁还有织纹的位置。要把两个孔连起来，抓两孔间的布桥，沿侧向拖动。可以分几次完成，中途松手会保留已经断开的部分。

**湿态抓取 / 泼水**使用相同的抓放操作。将指针放在袜面上按 **W** 加水，抓住湿处，反向拖回或松手可观察贴肤变化。水量、液色、黏度、吸收和湿摩擦等选项可在首次加水前设置。**Shift + W** 使用工程里配置的固定落点。

| 操作 | 作用 |
| --- | --- |
| 鼠标左键按住、拖动、松开 | 抓取当前可见的袜面，松开后可换点 |
| **Space** / **→** | 暂停或续播 / 暂停时单步 |
| **Shift + 左键** | 开启目标袜面监测后，选择探针 |
| **Enter** / **Esc** | 结束当前实时会话并封存袜面 |
| **结束实验并恢复原袜** | 清理交互副本，回到原来的袜面 |

## 材质与动作

配色、光学厚度和现场织纹尺寸可独立调节。加大光学厚度会降低透肤程度，改变现场织纹尺寸会调整可见针圈的大小。预张力、断裂伸长和脱圈传播影响拉扯、开孔与延伸。模型参数用于视觉交互，尚未用真实织物标定。

在 **单腿长筒袜** 中可选择袜口高度。实际抓取前应用高度。若要随动作测试，可先在 **准备动作贴肤** 中处理动作帧，再选择 **随骨架动作抓取**。更换皮肤、姿势动作或袜口高度后，重新准备对应帧。**目标袜面 · 实时监测**可检查当前探针位置的离肤距离、伸长或湿态读数。

## 保存与再次操作

保存前会自动结清输入并封存网格、孔岸、纱线和当步读数。重开有缺口的干态工程后，可在保存姿势点 **接着撕当前缺口**。湿态保存的是当时的外观与水量，重开后可查看或恢复原袜。实时手势和液量过程不会自动变为时间轴动画，固定回放和原角色关键帧仍可逐帧查看。
